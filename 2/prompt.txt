1. LAN Messenger —— 最推荐
真正的 Serverless LAN Messenger：
* Windows / macOS / Linux
* 不需要服务器、账号、互联网
* AES-256 + RSA-2048
* 文件传输
* 群组/联系人
* 消息历史
* 完全离线可用
目前官网提供 v1.3.9，适合直接部署使用。

技术栈比较现代：
Rust + Tauri + SQLite + WebSocket
支持：
* Windows
* Linux
* Android
* Web
* LAN 自动发现
* 文件传输
* 图片预览
* 消息记录

P2P + E2E 加密 + 无服务器

支持：
* Windows
* macOS
* Linux
* 一对一聊天
* 群组
* 文件
* 完全离线 LAN
* 无云服务、无账号依赖
如果是实验室、企业内网、隔离网络等场景，我会重点考虑它。
项目： https://github.com/OctopusGarage/mesh-talk
官网： https://octopusgarage.github.io/mesh-talk/
