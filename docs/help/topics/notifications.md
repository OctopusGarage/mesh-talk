# Control notifications and message previews

Choose whether notifications appear and whether they include message content.

## Change notification behavior

1. Open **More → Settings → Notifications & calls**.
2. Review notifications and message previews.
3. Review the experimental call and ringtone controls if calling is enabled.
4. Check the operating system's notification permission if the app's saved setting is enabled but no notification appears.

Disabling notifications retains the saved preview preference while making it inactive. Privacy & security shows preview status and links to this same editor.

## Protect previews

A device privacy preset can change message previews along with local locking and clipboard protections. After applying a preset, review the resulting values. Individual changes can produce the **Custom** privacy state.

See [Privacy controls](privacy.md) to separate local screen protection from network visibility.
