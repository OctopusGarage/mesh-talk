# Change the theme and wallpaper

Personalize the interface while keeping conversation content readable.

## Open appearance settings

1. Open **More → Settings → Appearance & language**.
2. Choose from the installed theme library and available wallpaper options.
3. Turn wallpaper visibility off if you prefer a quieter conversation surface.

The More menu also has a light/dark mode shortcut. Additional themes and artwork come from your installed customization packs.

## Across devices

Appearance can participate in linked-device synchronization when its category is enabled. This does not mean every machine setting synchronizes. Review **More → Link a device** for category choices.
